# TBC Arena Point Calculator

Link: https://maxmemixx.github.io/tbc-arena-point-calculator/

The application is hosted using GitHub pages and you can access it by simply clicking the link above.

The application calculates how many arena points you will receive based on your rating in the three brackets, 2v2, 3v3 and 5v5. You must play at least 10 games in a bracket to be eligible for points from that bracket. You receive arena points at the start of each weekly maintenance reset. The application is intended for The Burning Crusade Classic Anniversary servers.

The formula used to calculate arena points is from this forum post from a community manager at Blizzard - https://us.forums.blizzard.com/en/wow/t/calculating-arena-points-in-burning-crusade-classic-anniversary/2254395
